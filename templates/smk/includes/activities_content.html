The same five columns and the same markup as the protocol table, so the two read alike — №, мероприятие, исполнители, срок, статус. Every row comes from a measure's own `tasks` relation: one row for the shared task a measure produces, or one row per исполнитель when «Разбить задачу по исполнителям» was chosen. A measure whose task is missing is still listed, with «—» where the link would be, rather than being silently dropped. The record references the task and never restates it: the статус here is the task's own, and everything that acts on the work — completing it, attaching a file — happens on the task's page, which the № column links to. {% endcomment %}
