{% load people board_text %}{% comment %} A card's «Чат»: the live block `[data-live-board-comments]`. Read-only — the form to write a message (and to choose its files) is the drawer's, below this block and outside every block the live client replaces — so it is replaced whenever its fingerprint moves: a message, a file deleted. It is its own block, and nothing of it appears in the guarded panel: a message never changes `panel_revision`. Both views of the chat are here, and the chat's section says which one is shown (`data-board-chat-mode`, outside this block): - «Все сообщения» (`card.feed`, oldest first): every message with its files — images as thumbnails (`boards:file_preview`, opened full size in a new tab), any other file as a row (a badge by its type, the name cut to one line with the whole on `title`, the size, «Скачать»), a deleted one greyed as «Файл удалён» — and, among them by time, the files the card's task got before files moved into the chat (`tasks:download_attachment`; removed by the task's own rule and route). «×» beside a file is drawn for whoever may delete it, and asks through the shared confirmation modal. - «Только файлы» (`card.files`, newest first): every live file of the card, with who added it and when, and «К сообщению» — the row in the feed (every message is asked for when it is older than those shown). «@Имя Фамилия» of the people a message really mentions is highlighted (`board_text.with_mentions`: the text escaped first, the names wrapped after). Only the newest `COMMENTS_LIMIT` messages are read; «Показать ранние (N)» is this panel with `comments=all`, built by the server with the board's filter kept. The files of every message shown are one query, the older attachments the list the panel has read anyway. {% endcomment %}
