{% load people %}{% comment %} The card drawer: everything inside `
` of the board page, top to bottom — the heading, the tab strip, the three tab bodies. The page prints it, and `boards:fragment` returns it as `drawer_html` for `board_drawer.js` to insert when it opens a card without reloading the page; it composes the live blocks already rendered (`panel_html`, `card_html`, `checklist_html`, `facts_html`, `followers_html`, `comments_html`, `log_html`) and adds no markup of theirs. Which tab is shown is the `
`'s own `data-board-tab`, outside every block the live client replaces, so a replacement never changes the tab. The tab strip is links (`?tab=`), so without JavaScript a tab is a page; with it a tab is switched in place and the address follows. The number beside «Чат» and «Только файлы · N» are set again by the live client together with the messages' block. «Чат» shows every message or only the files (`data-board-chat-mode`, `&chat=files`): both lists are in its block, the mode is the section's attribute, switched in place like a tab. The guarded block has three containers — the heading (`[data-live-board-panel]`), the description or the card's form (`[data-live-board-card]`) and the facts with the tools (`[data-live-board-facts]`) — with one fingerprint. «Чат»'s messages (`[data-live-board-comments]`) and «Лог» (`[data-live-board-log]`) are read-only blocks of their own, and the chat's form is in no block at all, so a message being typed — and the files chosen for it — are never redrawn. So are the card's «Чек-лист» on «Описание» (`[data-live-board-checklist]`, between the description and the facts, with «Добавить пункт» below it in no block) and its «Подписчики» (`[data-live-board-followers]`, below the facts). The markup is in the order of the screen, so the focus follows it. {% endcomment %}
