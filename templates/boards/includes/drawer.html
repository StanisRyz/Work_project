{% load people %}{% comment %} The card drawer: everything inside `
` of the board page, top to bottom — the heading, the tab strip, the four tab bodies. The page prints it, and `boards:fragment` returns it as `drawer_html` for `board_drawer.js` to insert when it opens a card without reloading the page; it composes the live blocks already rendered (`panel_html`, `card_html`, `comments_html`, `log_html`) and adds no markup of theirs. Which tab is shown is the `
`'s own `data-board-tab`, outside every block the live client replaces, so a replacement never changes the tab. The tab strip is links (`?tab=`), so without JavaScript a tab is a page; with it a tab is switched in place and the address follows. The numbers beside «Чат» and «Файлы» are set again by the live client together with their blocks. The guarded block has two containers — the heading (`[data-live-board-panel]`) and the forms and files (`[data-live-board-card]`) — with one fingerprint. «Чат»'s messages (`[data-live-board-comments]`) and «Лог» (`[data-live-board-log]`) are read-only blocks of their own, and the chat's form is in no block at all, so a message being typed is never redrawn. So is the card's «Чек-лист» on «Описание» (`[data-live-board-checklist]`), with «Добавить пункт» below it in no block. {% endcomment %}
