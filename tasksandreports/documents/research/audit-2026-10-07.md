# «Документация»: разбор текущего состояния (7 октября 2026)

Разбор кода `documents/` на коммите `01cd2b4`: права, сервисы, страницы,
загрузка, предпросмотр, извлечение текста, поиск, ZIP. Уязвимости найдены
чтением кода, запуском не подтверждались — каждая проверяется тестом на этапе,
который её закрывает (`../plan.md`).

## Сильные стороны

- **Хранение.** Путь на диске — `media/documents/library/<папка>/<uuid>.<ext>`,
  без пользовательского текста; `MEDIA_ROOT` не публикуется веб-сервером. Файл
  отдают только представления `documents`, каждый раз заново спрашивая право;
  отказ и отсутствие файла — один и тот же 404.
- **Предпросмотр.** Тип для показа берётся из расширения по карте
  `documents/preview.py`, а не из присланного браузером. HTML и SVG инлайн не
  отдаются никогда; ответ идёт с `nosniff` и
  `Content-Security-Policy: sandbox; frame-ancestors 'self'`.
- **Версии только добавляются.** Номер выдаётся под блокировкой документа,
  `documents_version_single_current` — слово базы о единственной текущей
  версии, «что изменилось» обязательно со второй версии.
- **Согласование, ознакомление и пересмотр — задачи общего модуля «Задачи»**
  (`DOCUMENT_APPROVAL`, `DOCUMENT_ACK`, `DOCUMENT_REVIEW`) с уникальными
  ограничениями против дублей.
- **Одно правило видимости.** `can_view_folder()` и его списочный двойник
  `visible_folder_ids()`: ограничение папки наследуется вниз; поиск,
  «Недавние», «Избранное», «Нормативные документы» акта и протокола, адресаты
  ознакомления и подписчики фильтруются им же. Закрытая папка отвечает 404.
- **Корзина.** Документ, по которому выдавались задачи, не удаляется навсегда
  (`Task.document_version` — `PROTECT`); файлы стираются только `on_commit`.
- **«Вложения» только для чтения**, право на каждый файл спрашивается у
  модуля-владельца (`documents/references.py`).
- **Имена файлов.** `safe_document_name()` убирает пути и всё
  непечатаемое, включая U+202E (трюк «фото‮fdp.exe»); `FileResponse`
  кодирует имя по RFC 6266.
- **Поиск по тексту** с подсветкой; фрагмент экранируется до вставки `<mark>`.

## Уязвимости

| # | Риск | Где | Суть |
|---|---|---|---|
| У-1 | высокий | `text_extraction._office_text()` | «Zip-бомба»: части `.docx/.xlsx/.pptx` распаковываются `archive.read()` целиком, без проверки размера после распаковки и степени сжатия. 25 МБ могут развернуться в десятки гигабайт — процесс падает при загрузке и в `reindex_documents`. Загружают ответственные, но файл легко получить со стороны. |
| У-2 | высокий | `requirements.txt`: `pypdf==5.1.0` | Для pypdf ниже 6.x публиковались уязвимости «PDF съедает память или зацикливается» (например, CVE-2025-55197). `MAX_PDF_PAGES` от этого не защищает. |
| У-3 | средний | `views._zip_response()` | «Скачать ZIP» может любой читатель; нет лимита на число и объём файлов, каждый файл читается в память целиком (`handle.read()`). |
| У-4 | средний | `validators.py` | Проверяется только расширение: сигнатура файла не сверяется, антивируса нет. Разрешены `.doc/.xls/.ppt/.rtf` — основной путь макросов и эксплойтов. |
| У-5 | средний | развёртывание | Лимит 25 МБ проверяется после приёма всего тела запроса; лимита размера тела на прокси в `docs/deployment.md` нет. Множественная загрузка не ограничена по числу файлов. |
| У-6 | низкий | предпросмотр PDF | PDF может нести JavaScript; сейчас его гасит `sandbox`. Ослабление CSP ради совместимости сняло бы защиту. |
| У-7 | низкий | `views._stream_version()` | При скачивании `Content-Type` — тот, что прислал браузер при загрузке. Отдаётся «на скачивание» с `nosniff`, риск мал, но тип стоит брать из расширения, как в предпросмотре. |

## Ошибки логики и пробелы контроля (ISO 9001 §7.5)

| # | Где | Суть |
|---|---|---|
| Л-1 | `restore_document_version()` | Возврат старой версии — просто перенос `is_current`: без согласования; не вызывает `_put_version_in_force()` (открытые ознакомления заменённой версии висят, новые не рассылаются, подписчики не узнают); статус согласования проверяется до блокировки строки. |
| Л-2 | `add_document_version()` | Согласующим можно назначить того, кому папка закрыта: он получит задачу, а документ откроется ему как «не найден» — круг застрянет. Ознакомление такую проверку делает, согласование — нет. |
| Л-3 | `can_download_document_version()` | Версия на согласовании и возвращённая видны и скачиваются всеми читателями — риск работы по неутверждённому тексту. |
| Л-4 | `_record_history()` | Ошибка записи истории только логируется — пропуски в истории документа. |
| Л-5 | `set_folder_access()` | Смена прав на папку — без события в истории и без блокировки. Скачивания и просмотры есть только в техническом логе, который ротируется. |
| Л-6 | `DocumentVersion` | Нет контрольной суммы: нельзя доказать, что файл на диске — тот, что согласовали; дубли не находятся. |
