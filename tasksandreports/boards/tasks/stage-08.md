# Agile-доски, этап 8 (необязательный): доводка перед пилотом

Работа — прямо в `main` (см. `tasksandreports/README.md`). Этап маленький:
две доработки по замечаниям этапа 7 и проверка готовности к развёртыванию.

Прочитай `reviews/stage-07.md` и разделы `AGENTS.md` про доски и про черновик
«Выполнения» (`tasks/drafts.py`, `[data-attachment-carry-from]`).

## 1. Сообщение не теряет недописанное «Выполнение»
- Форма сообщения в «Обсуждении» несёт скрытое поле `execution_comment` с
  `[data-attachment-carry-from="#task-execution-comment"]`, как формы
  вложений. Его заполнит существующий делегированный слушатель
  `attachment_upload.js`, нового JS не нужно.
- `boards:card_comment` при успехе и при отказе кладёт его в сессию через
  `tasks.drafts.remember_execution_draft()`. Панель уже забирает черновик при
  отрисовке.
- Это черновик, а не результат: `complete_task()` по-прежнему единственный
  писатель `Task.execution_comment`.
- Тесты:
  - после отправки сообщения поле «Выполнения» содержит прежний текст;
  - пустой черновик очищает старый;
  - черновик чужой задачи не подставляется.

## 2. Длинное обсуждение
- Панель показывает последние 100 сообщений и ссылку «Показать ранние (N)» —
  тот же адрес с `&comments=all`, который сохраняет фильтр доски.
- Фрагмент понимает тот же параметр.
- Лимит — константа в `boards/selectors.py`, срез делается в запросе, а не в
  шаблоне.
- Тест на постоянное число запросов и тест «фрагмент равен странице» с этим
  параметром.

## 3. Готовность к развёртыванию (только проверка, без изменений, если всё зелёное)
Прогони и приложи итоговые строки:

    python manage.py check
    python manage.py makemigrations --check --dry-run
    python manage.py test --parallel 4
    python manage.py check_documentation
    python manage.py check_logging
    python manage.py check_realtime_transport
    python manage.py check_fresh_bootstrap
    python manage.py check_production_readiness   (с production-настройками из .env.example)
    node realtime/tests/js/realtime_client_test.js

Также:
- `migrate` с нуля и откат миграций `boards` до `zero` на PostgreSQL;
- полный `test` на PostgreSQL. Падения, которые есть и на `main` до досок,
  перечисли отдельно — их не чинить.

Если какая-то проверка падает из-за досок — исправь и опиши.
