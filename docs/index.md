# Карта документации

Документы описывают **текущее состояние** приложения. История изменений
хранится в Git, а не в тексте документов.

## Активные документы

| Документ | Какую задачу решает |
| --- | --- |
| [README.md](../README.md) | быстрый вход: назначение системы, стек, локальный запуск, ссылки |
| [AGENTS.md](../AGENTS.md) | правила внесения изменений в код, инварианты, обязательные проверки |
| [Архитектура](architecture.md) | из чего состоит система, кто за что отвечает, направления зависимостей, источники истины |
| [Предметная область](domain.md) | роли, видимость актов, статусы и переходы, задачи, уведомления |
| [Разработка](development.md) | окружение, зависимости, база, миграции, справочники, запуск, тесты |
| [Real-time](realtime.md) | контракт событий, Redis Pub/Sub, SSE, сверка, fallback polling, вкладки |
| [Развёртывание](deployment.md) | production-окружение, чистый bootstrap PostgreSQL, ASGI, proxy, Redis, SMTP, health |
| [Эксплуатация](operations.md) | журнал, `request_id`, расследование инцидента, health, email worker, диагностика |
| [Резервное копирование и восстановление](backup_restore.md) | состав копии, согласованность базы и файлов, чек-лист восстановления |

## Что читать перед изменением

| Что меняете | Читать сначала |
| --- | --- |
| Workflow акта, статусы, права, задачи | [domain.md](domain.md), затем [AGENTS.md](../AGENTS.md) |
| События, SSE, сверка, поведение вкладок | [realtime.md](realtime.md) |
| Новое приложение, слои, зависимости между модулями | [architecture.md](architecture.md) |
| Развёртывание, переменные окружения, reverse proxy, Redis, SMTP | [deployment.md](deployment.md) и `.env.example` |
| Логирование, диагностика, health, email worker | [operations.md](operations.md) |
| Резервное копирование и восстановление | [backup_restore.md](backup_restore.md) |
| Локальный запуск, тесты, отладка | [development.md](development.md) |

## Единые источники истины

| Что | Где |
| --- | --- |
| Точные версии зависимостей | `requirements.txt` |
| Полный список переменных окружения | `.env.example` и `ecosystem/settings.py` |
| Бизнес-модель и workflow | [domain.md](domain.md) |
| Архитектура и слои | [architecture.md](architecture.md) |
| Real-time | [realtime.md](realtime.md) |

Документы не дублируют друг друга: если утверждение относится к чужой зоне
ответственности, вместо копии ставится ссылка.

## Проверка документации

```powershell
python manage.py check_documentation
```

Команда только читает: проверяет относительные ссылки, отсутствие исторических
маркеров этапов в активных документах, наличие предупреждения в архивных,
существование упомянутых management-команд, непустые документы и один
заголовок H1 на документ.
