# Интерфейс: визуальный стиль

Как выглядят страницы и из чего собирается их оформление. Поведение
компонентов (реестры, модальное окно, загрузка вложений, живые фрагменты)
описано в [AGENTS.md](../AGENTS.md); здесь — только внешний вид.

## Принципы

Система — рабочий инструмент цеха и служб качества, а не витрина. Отсюда
четыре правила, которым подчинено всё остальное:

1. **Нейтральная основа.** Графитовый текст на светло-сером фоне, белые
   карточки, разделённые тонкой рамкой, а не тенью. Тень есть только у того,
   что лежит поверх страницы: меню, диалоги, липкие панели действий.
2. **Один акцент.** Глубокий стальной синий (`--color-primary`) означает
   «можно нажать» или «текущее»: ссылка, основная кнопка, активная вкладка,
   текущий этап маршрута. Для украшения он не используется.
3. **Цвет — только со смыслом.** Красный — просрочено, запрещено, ошибка;
   янтарный — внимание, возврат, доработка; зелёный — выполнено, разрешено.
   Ноль просроченных не краснеет, дата «через 3 дня» не подсвечивается.
4. **Одна основная кнопка на экран.** Заполненная кнопка — действие, которое
   двигает документ вперёд («Создать акт», «Передать в ТО», «Утвердить»).
   Возврат, удаление, добавление строки и путь без JavaScript («Применить»)
   оформляются контуром.

## Токены

Все значения живут один раз — в `:root` файла `static/css/base.css`. Модуль
называет токен и не повторяет ни цвет, ни размер.

| Группа | Токены | Назначение |
| --- | --- | --- |
| Акцент | `--color-primary`, `--color-primary-dark`, `--color-primary-soft`, `--color-primary-border` | ссылки, основная кнопка, активное состояние, его фон и рамка |
| Нейтральные | `--color-bg`, `--color-surface`, `--color-surface-muted`, `--color-hover`, `--color-text`, `--color-muted`, `--color-subtle`, `--color-border`, `--color-border-strong` | фон страницы, карточка, шапка таблицы и вложенный блок, наведение, три уровня текста, две рамки |
| Смысл | `--color-success*`, `--color-warning*`, `--color-danger*` | у каждого — цвет текста, `-soft` (фон) и `-border` (рамка) |
| Этапы акта | `--stage-otk`, `--stage-ko`, `--stage-to`, `--stage-review`, `--stage-actions`, `--stage-done`, `--stage-closed`, `--stage-cancelled` | цвет точки в метке статуса |
| Форма | `--radius` (6px), `--radius-sm` (4px), `--shadow-overlay`, `--shadow-sticky`, `--focus-ring` | скругления, тени всплывающего и липкого, кольцо фокуса |
| Шрифт | `--font-family` | Segoe UI на рабочих станциях Windows, системный гротеск в остальных случаях |
| Плотность | `--font-size-base`, `--control-height`, `--control-padding`, `--control-font-size`, `--cell-padding` | 14px текст, 34px поле и кнопка, отступы ячейки |

Цифры в таблицах, датах и счётчиках моноширинные по ширине
(`font-variant-numeric: tabular-nums`), поэтому столбцы чисел и дат стоят
ровно.

## Компоненты

- **Кнопки** — `.link-button` и один модификатор: `--secondary` (белая с
  рамкой), `--warning` и `--danger` (контур янтарный и красный),
  `--success` (зелёный контур), `--compact` (плотная). Фокус — кольцо
  `--focus-ring`, а не системная обводка.
- **Поля** — рамка `--color-border`, при наведении `--color-border-strong`,
  при фокусе — акцентная рамка и кольцо; правило общее, в `components.css`.
- **Статус акта** — нейтральная метка с цветной точкой этапа:
  `act-badge--status act-badge--<код статуса>` в реестре и
  `act-stage-badge act-stage-badge--<код статуса>` в шапке акта. Метка без
  кода (задачи, протоколы) получает нейтральную точку.
- **Решение КО** — `act-badge--decision act-badge--decision-<код решения>`:
  цвет несёт сам фон, потому что это вердикт — «Запретить использование»
  красное, «с доработкой» янтарное, разрешающие зелёные.
- **Срок** — `includes/due_date.html`: обычная дата; подкрашиваются только
  просроченный и наступающий срок.
- **Вкладки** — подчёркивание 2px акцентом под активной, текст активной
  вкладки основного цвета, счётчик рядом в `.tab-count`.
- **Карточки** — `.detail-section`, `.table-card`: белый фон, рамка,
  `--radius`, без тени.

## Страницы актов

- **Реестр.** Вкладки и «Создать акт» в одной строке; под ними — счётчики как
  быстрые фильтры (каждый шириной в свой текст, активный — на
  `--color-primary-soft`, «Просрочено» краснеет только при ненулевом
  значении); затем строка фильтров и таблица — одна панель: фильтры служат
  панелью инструментов списка. В таблице есть «Наименование продукции» — тот
  же столбец, что уже выгружается в Excel.
- **Карточка акта.** Шапка — одна карточка: кнопка «назад», номер, статус с
  точкой этапа, строка фактов «Создан · Срок · Тип» и под тонкой линией
  маршрут согласования (пройденные этапы — зелёные, текущий — акцентный).
  Ниже вкладки и разделы «Проработки»; кнопки маршрута — в липкой панели у
  нижнего края окна.
- **Создание и редактирование.** Тот же заголовок, разделы пронумерованы
  («1 Данные акта», «2 Дефекты») счётчиком CSS; каждый дефект — отдельный
  вложенный блок на `--color-surface-muted`, заголовок «Дефект N» появляется
  у всех блоков, как только их больше одного; «Добавить ещё дефект» —
  пунктирная заготовка следующего блока; кнопки формы — в липкой панели.

На экранах уже 760px липкие панели становятся обычными, а «Данные акта»
выстраиваются подписью над значением.
