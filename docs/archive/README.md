# Архив документации

> **Внимание. Документы в этом каталоге исторические.**
>
> - они описывают состояние проекта на момент написания и **могут не
>   соответствовать текущему коду**;
> - они **не являются инструкцией** для новых изменений;
> - актуальные документы перечислены в [docs/index.md](../index.md).

Архив существует по одной причине: часть материалов остаётся полезной для
сопровождения старых данных и уже написанных технических инструментов, даже
когда сам сценарий не является текущим. Всё остальное удалено — история
изменений хранится в Git.

## Чем архив не является

Production создаётся как **чистая установка на пустой PostgreSQL**, без
переноса текущей development-базы SQLite. Инструменты переноса из этого архива
применяются только в отдельно согласованном сценарии миграции существующих
данных. Порядок первого запуска — в
[docs/deployment.md](../deployment.md).

Исторические обозначения этапов (D…, RT-…, STAB-…, OBS-…) допустимы только
внутри этого каталога.
